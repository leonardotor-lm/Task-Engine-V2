# Proyecto

## Filosofía

La aplicación debe ayudar a organizar el trabajo sin aumentar la carga cognitiva.

Debe ser:

- clara;
- rápida;
- estable;
- escalable;
- fácil de mantener.

La complejidad debe aparecer únicamente cuando el usuario la necesite.

## Fuente de verdad del backlog

`docs/roadmap/PENDIENTES.md` es la fuente de verdad de los pendientes vigentes de Task Engine.

Antes de responder qué falta, planificar una mejora o reconstruir trabajo pendiente, se debe:

1. leer `docs/roadmap/PENDIENTES.md`;
2. contrastarlo con los issues abiertos y las PR activas/fusionadas;
3. considerar terminado cualquier punto cuyo issue esté cerrado como completado o cuya implementación fusionada ya esté verificada;
4. dar prioridad al estado actual del repositorio frente a conversaciones o memoria histórica;
5. actualizar `PENDIENTES.md` en la misma PR cuando un pendiente se agrega, cambia de estado o se completa.

No se debe reconstruir el backlog únicamente desde memoria o conversaciones previas.
